Chrome 扩展

在 ChatGPT、Gemini、Claude 页面里直接导入当前对话。

安装

  1. 打开 Chrome 的 chrome://extensions/。
  2. 开启 Developer mode。
  3. 点击 Load unpacked，选择项目里的 browser-extension 目录。
  4. 打开扩展设置，填入下面两项。

这个 token 只用于浏览器扩展导入，不影响私有 Podcast Feed。

使用

  1. 正常打开 ChatGPT、Gemini 或 Claude 对话页。
  2. 点击右下角的“导入 PocketReader”。
  3. 检查标题、朗读范围和声音，然后提交。
